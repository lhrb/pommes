# Visual & UX Direction

## aestetic
- low resolution neo retro pixel style.
- mobile first but usable on pc
- Use Tiny Timmy or a similarly legible pixel font for headings, buttons and numbers. Tiny Timmy is a retro-inspired pixel font available as a web font. Use a normal sans-serif for longer descriptions when the pixel font becomes difficult to read.

### general layout

Every page lives inside one persistent mobile game interface:

- header picture
- player stats
- page screen 
- bottom navigation
  - game, dishes, actions, research, black market always clickable
  - pop up/extend: stats page, chronic page, wiki 
- touch targets at least 44px high
